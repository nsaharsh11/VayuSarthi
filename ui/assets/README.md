# Visual assets

All assets are stored in this repository and displayed locally. The app makes
no image-generation, remote image, font or CDN requests.

- `hangar.png`: original generated concept illustration of a fictional
  civilian aircraft and maintenance equipment. Created with the built-in
  image-generation tool during project preparation. It is not a fleet photo,
  benchmark result or representation of the selected pack's resource counts.
- `wordmark.svg`: project-native aircraft mark and wordmark, authored as SVG.
- `workflow.svg`: project-native explanatory workflow diagram, authored as SVG.
  The step numbers indicate sequence, not measured results.

## Prompt for the hangar illustration

Use case: stylized-concept. Asset type: wide header illustration for Vayu Sarthi,
a light-themed offline aircraft-maintenance planning prototype. Create an
original refined isometric 3D illustration of a fictional civilian passenger
aircraft inside a bright minimalist maintenance hangar, with an engine on a
maintenance stand and a compact technician tool cart. Simplified geometric
architecture, precise graceful proportions, soft shadows, premium editorial
product illustration, warm ivory and pale blue-gray background, deep navy
structural lines, muted teal accents and tiny amber details matching a
restrained technical dashboard. Wide panoramic composition approximately 2.5:1,
aircraft and maintenance objects comfortably inside the frame, clean breathing
room, no clutter. No text, no labels, no charts, no numbers, no logos, no national
markings, no military equipment, no identifiable people. Clearly an illustration
rather than a photograph. This will be stored locally in the repo and captioned
as a fictional concept scene; it represents no measured fleet or actual
resource counts.
